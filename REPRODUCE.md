# Reproducing the experiments

Raw organic data is not included (platform terms and user privacy), so the pipeline needs your own InfoMiner API key
(`INFOMINER_KEY` in `.env`) and an OpenAI-compatible LLM endpoint (`CHAT_URL`, `CHAT_MODEL`; we used a self-hosted Gemma-4-31B).
The S4/S5 detector-evasion instructions (`EVASIVE` in `src/swarm.py`) are redacted in this public release; they are available to verified researchers on request.

## Pipeline (in order)
```bash
uv sync
python src/fetch_organic.py 9 2026-10-18          # dev: root posts 10/18-10/26 -> data/organic_raw*.jsonl (needs INFOMINER_KEY in .env)
python src/fetch_organic.py 5 2026-10-28 data/heldout/organic_raw.jsonl   # held-out: root posts 10/28-11/1
python src/build_organic.py                       # -> data/organic_msgs.json, organic_delays.json
python src/swarm.py S0,S1,S2,S3,S4,S5 0,1,2       # Gemma-4-31B (self-hosted vLLM) swarms -> data/swarm_*.json
python src/extract.py                             # (target, stance, claim) per message -> data/claims.json
python src/detect.py S0,S1,S2,S3,S4,S5 0,1,2      # D1-D5 + PayloadConv (D4) -> data/results.json
python src/sens.py                                # swarm-size / merge-ratio sensitivity
python src/figs.py                                # report/figs/*
TARGET_BRAND=可不可 TARGET_TAG=k python src/swarm.py S4 0,1,2   # established-brand control (reuses S4 plans); also 迷客夏/m
python src/detect.py S0,S1,S2,S3,S4,S5,S4k,S4m 0,1,2   # incl. A1 account-only, D4-on-D5-sample, D5+context controls
python src/ops.py                                 # frozen 0.5% alert threshold from organic-only dev data -> data/ops.json
python src/controls_table.py                      # report/figs/controls.tex
python src/audit.py sample && python src/audit.py run && python src/audit.py score   # blind Gemini 3.8 Flash audit via `agy` (sends 300 public message texts, no account IDs, to Google)
# cross-family replication: swarms generated by Gemini 3.8 Flash via `agy` (sends organic root-post excerpts and style exemplars, no account IDs, to Google)
GEN_BACKEND=agy LLM_CONC=16 AGY_CWD=<empty dir> python src/swarm.py S1,S2,S3,S4,S5 0,1,2   # -> data/swarm_S*G_s*.json
python src/gemini_clean.py                         # drop refusals (raw kept as *.raw.json) -> data/gemini_refusals.json
python src/extract.py && RESULTS=results_gemini.json python src/detect.py S1G,S2G,S3G,S4G,S5G
python src/crossfamily_table.py && python src/ops_gemini.py   # report/figs/crossfamily.tex, data/ops_gemini.json
DATA_DIR=data/heldout ...                         # same pipeline on the held-out window
```
`CHAT_URL` and `CHAT_MODEL` choose the LLM endpoint. The default is the self-hosted H200 Gemma-4-31B.
Every generation salt includes the window tag (`WIN`, default = name of `DATA_DIR`), so the two windows never share cached LLM outputs.
Each synthetic agent lives on one platform (organic accounts never span platforms); `detect.py` reports an `X platforms` shortcut check, which must stay at AUROC 0.5.
`extract.py` shows each comment together with its root post, and its cache re-extracts any entry whose prompt changed.
Copy `data/heldout/results.json` to `data/results_heldout.json` before running `figs.py _heldout`.

## Files
- `src/swarm.py`: the swarm conditions. S0 is template bots; S1 a naive LLM swarm; S2 persona-conditioned agents; S3 an orchestrated swarm; S4 an evasive swarm; S5 adaptive self-seeding.
- `src/detect.py`: D1 lexical, D2 temporal co-activity, D3 semantic density, D4 PayloadConv (plus the D4a/b/c ablations), D5 per-account LLM monitor, and the ensemble.
- `report/main.tex`: the submission report (build with xelatex).

## Files
- `src/swarm.py`: swarm conditions S0 (template bots), S1 (naive LLM swarm), S2 (personas), S3 (orchestrated), S4 (detector-aware), S5 (self-seeding).
- `src/extract.py`: per-message (target, stance, claim) extraction.
- `src/detect.py`: D1 lexical, D2 temporal co-activity, D3 semantic density, D4 PayloadConv (and ablations D4a/b/c/d), D5 per-account LLM monitor, controls.
- `src/ops.py`, `src/ops_gemini.py`: frozen alert threshold. `src/audit.py`: independent-model audit. `src/gemini_clean.py`, `src/crossfamily_table.py`: cross-family replication.
- `report/main.tex`: report source (build with xelatex).
